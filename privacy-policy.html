Privacy Policy — Tiny Craft Factory

Last updated: 2026-09-26

Tiny Craft Factory is a personal, single-user automation tool operated by its owner ("we", "the developer"). It generates short craft videos and publishes them to the developer's own social media accounts, including TikTok. This policy describes how it handles data when connecting to TikTok's API.

Who this applies to

This application is not a public service. It is used only by its owner, to publish the owner's own content to the owner's own TikTok account. It is not distributed to, or used by, the general public.

What data we access

When the owner authorizes this application via TikTok's OAuth login, the application receives an access token and refresh token scoped to the owner's own TikTok account, limited to permission to publish video content and read basic profile information (open ID). No data about any other TikTok user is accessed.

Where data is stored

OAuth tokens are stored only in a local file on the developer's own computer. They are never transmitted to, or stored on, any third-party server. No database of user data is maintained.

What we upload

The only content sent to TikTok is video files created entirely by the owner's own production process, published directly to the owner's own TikTok account via TikTok's Content Posting API.

Data sharing

We do not sell, rent, or share any data with third parties. The only external service this application communicates with is TikTok's own API, solely to publish the owner's content and check publish status.

Data retention and deletion

Locally stored tokens can be deleted at any time by removing the token file from the local machine. Revoking access via TikTok's account settings immediately invalidates any stored token.

Contact

Questions about this policy can be sent to the developer via the contact details provided in the TikTok Developer Portal app listing.

This document applies to the "Tiny Craft Factory" TikTok API integration only.
