Privacy Policy — Tadaa Scheduler

Last updated: 2026-10-24

Tadaa Scheduler is a personal, single-user automation tool operated by its owner ("we", "the developer"). It schedules and publishes the developer's own videos and posts to the developer's own social media accounts, including TikTok and YouTube, using a self-hosted copy of the open-source scheduling software Postiz running on the developer's own computer. This policy describes how it handles data when connecting to these platforms' APIs.

Who this applies to

This application is not a public service. It is used only by its owner, to publish the owner's own content to the owner's own accounts. It is not distributed to, or used by, the general public, and no other user accounts are supported.

What data we access

When the owner authorizes this application via TikTok's OAuth login, the application receives an access token and refresh token for the owner's own TikTok account. It uses them only to:

  • read basic profile information (open ID, display name and avatar);
  • read account statistics (such as follower and video counts) and the list of the owner's own videos, to show the owner how their posts perform;
  • upload and publish videos that the owner has scheduled.

When the owner connects YouTube, equivalent access to the owner's own YouTube channel is granted through Google's OAuth login and used in the same way. No data about any other TikTok or YouTube user is accessed.

Where data is stored

OAuth tokens, profile information and scheduled posts are stored in a database that runs only on the developer's own computer. This data is not stored on any server operated by a third party.

What we upload

The only content sent to TikTok or YouTube is video content created by the owner, published to the owner's own account through each platform's official API (for TikTok, the Content Posting API).

Data sharing

We do not sell, rent, or share any data with third parties. The application communicates only with the official APIs of the platforms the owner connects (TikTok and YouTube).

Because the application runs on a local computer without its own public web address, the TikTok login redirect passes through a public redirect service (redirectmeto.com) to reach the local application. Only the one-time authorization code passes through that service. The code cannot be used without the application's client secret, which never leaves the developer's computer.

Data retention and deletion

Data is kept only for as long as the owner uses the application. All locally stored data, including tokens, can be removed at any time by deleting the local database. Revoking access in TikTok's or Google's account settings immediately invalidates any stored token.

Contact

Questions about this policy can be sent to the developer via the contact details provided in the TikTok Developer Portal app listing.

This document applies to the "Tadaa Scheduler" TikTok and YouTube API integrations only.
